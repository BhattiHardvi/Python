# Python Basic Programs

This repository contains beginner-friendly Python programs using concepts like:
- Input/Output
- Conditional Statements
- Loops
- Match-Case
- Type Casting
- Functions like `type()` and `id()`

---

# Programs Included

## 1. Student Grade Checker
### Description
Takes student name and marks as input.  
Displays grade using `if-elif-else`.  
Also prints datatype and memory address using `type()` and `id()`.

### Concepts Used
- input()
- if-elif-else
- type()
- id()

---

## 2. Simple Calculator
### Description
Accepts two numbers and an operator from the user.  
Uses `match-case` to perform:
- Addition
- Subtraction
- Multiplication
- Division

### Concepts Used
- match-case
- Arithmetic Operators
- User Input

---

## 3. Even/Odd & Positive/Negative Checker
### Description
Inputs a number and checks:
- Even or Odd
- Positive or Negative

Uses nested `if` statements.

### Concepts Used
- Nested if
- Modulus Operator `%`

---

## 4. Multiplication Table Generator
### Description
Takes a number from the user and prints its multiplication table using `for` loop and `range()`.

### Concepts Used
- for loop
- range()

## 5. Datatype Converter Program
### Description
Takes user input and converts it into:
- int
