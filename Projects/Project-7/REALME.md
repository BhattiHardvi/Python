# Multi-Utility Toolkit

## 📌 Project Overview

The **Multi-Utility Toolkit** is a Python package that combines multiple useful utilities into a single menu-driven application. It demonstrates the use of Python's built-in modules such as `datetime`, `math`, `random`, `uuid`, file handling, and the `dir()` function.

This project is designed for beginners to understand Python modules, functions, packages, loops, conditionals, and file operations.

---

## 🚀 Features

### 1. Datetime and Time Operations
- Display current date and time
- Calculate difference between two dates
- Display formatted date and time
- Stopwatch
- Countdown timer

### 2. Mathematical Operations
- Calculate factorial
- Compound interest calculator
- Trigonometric calculations (Sin, Cos, Tan)
- Area of a circle

### 3. Random Data Generation
- Generate random numbers
- Generate random lists
- Generate random passwords
- Generate random OTPs

### 4. UUID Generator
- Generate unique UUID (Version 4)

### 5. File Operations
- Create a new file
- Write data to a file
- Read data from a file
- Append data to a file

### 6. Module Explorer
- Display available attributes using `dir()` for:
  - datetime
  - math
  - random
  - uuid

1. Install Python 3.x

2. Clone or download the project.

3. Open terminal in the project folder.

4. Run:

```bash
python main.py
```
