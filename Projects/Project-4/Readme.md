# 📊 Data Analyzer and Transformer Program (Python)

## 📌 Overview
This is a menu-driven Python program that performs various data analysis and transformation operations on a 1D dataset. It demonstrates the use of functions, recursion, lambda functions, sorting, and basic statistics.

---

## 🚀 Features

The program provides the following functionalities:

1. **Input Data**
   - Enter a 1D array of integers separated by spaces.

2. **Display Data Summary**
   - Total elements
   - Minimum value
   - Maximum value
   - Sum of values
   - Average value

3. **Calculate Factorial (Recursion)**
   - Computes factorial of a given number using recursion.

4. **Filter Data by Threshold (Lambda Function)**
   - Displays values greater than or equal to a user-defined threshold.

5. **Sort Data**
   - Sorts data in ascending or descending order.

6. **Dataset Statistics**
   - Minimum, Maximum, Sum, and Average of dataset.

7. **Exit Program**

---

## 🧠 Concepts Used

- Python Functions
- Recursion
- Lambda Functions
- Lists
- Loops (while loop)
- Conditional statements
- Built-in functions (`min`, `max`, `sum`, `len`)
- Sorting (`sort()`)
