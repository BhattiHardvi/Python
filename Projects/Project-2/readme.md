# Pattern Generator and Number Analyzer

A simple Python console application that allows users to:

- Generate a star (`*`) pattern
- Analyze numbers in a given range
- Check whether numbers are even or odd
- Calculate the sum of numbers in the range

---

## Features

### 1. Pattern Generator
- Takes the number of rows from the user
- Prints a triangle star pattern

Example:
```bash
*
**
***
****
*****
```

### 2. Number Analyzer
- Accepts a start and end range
- Checks each number as:
  - Even
  - Odd
- Calculates the total sum of all numbers in the range

### 3. Exit Option
- Safely exits the program
