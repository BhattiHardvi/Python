# Interactive Personal Data Collector 🧑‍💻

A simple Python program that collects personal information from the user and displays:
- Name
- Age
- Height
- Favourite Number
- Data Types
- Memory Addresses
- Approximate Birth Year

## 📌 Features
- Uses `input()` for user interaction
- Demonstrates Python data types
- Shows memory addresses using `id()`
- Calculates approximate birth year
- Beginner-friendly Python project

## 🛠️ Technologies Used
- Python 3

## ▶️ How to Run

1. Install Python
2. Save the file as `Interactive_Data_Collector.py`
3. Open terminal or command prompt
4. Run the program:

```bash
python Interactive_Data_Collector.py
