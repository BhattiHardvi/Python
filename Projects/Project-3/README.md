# Student Data Organizer

## Project Description

Student Data Organizer is a menu-driven Python application that helps manage student records. Users can add, view, update, and delete student information, as well as display all subjects offered by students.

## Features

1. Add Student Details
2. Display All Students
3. Update Student Information
4. Delete Student Records
5. Display Subjects Offered
6. Exit Program

## Technologies Used

* Python
* Lists
* Dictionaries
* Loops
* Conditional Statements
* Sets
* String Manipulation

## Data Stored for Each Student

* Student ID
* Name
* Age
* Grade
* Date of Birth
* Subjects

## How the Program Works

### 1. Add Student

The user enters:

* Student ID
* Name
* Age
* Grade
* Date of Birth
* Subjects (comma-separated)

The details are stored in a dictionary and added to a list.

### 2. Display All Students

Displays all student records including:

* Student ID
* Name
* Age
* Grade
* Subjects

### 3. Update Student Information

The user enters a Student ID.
If the ID exists, the student information is updated.

### 4. Delete Student

The user enters a Student ID.
If found, the student record is removed from the list.

### 5. Display Subjects Offered

Uses a set to collect unique subjects from all students and displays them.

### 6. Exit

Terminates the program.
